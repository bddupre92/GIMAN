# SYNTHETIC DATA ONLY

**THIS DIRECTORY CONTAINS ONLY COMPUTATIONALLY GENERATED SYNTHETIC DATA.**

**It does NOT contain real patient data from PPMI, BioFIND, PDBP, HBS, or any other clinical cohort.**

The synthetic wearable data in this directory is generated by `wearable/generator.py` to demonstrate
future integration possibilities with wearable sensors (accelerometers, heart rate monitors, sleep
trackers). Values are stage-correlated random samples, not measurements from real patients.

## Strict Data Isolation

- Real PPMI data lives in `../data/` (project root)
- Synthetic data lives HERE in `synthetic_data/`
- These directories are NEVER mixed in any API or analysis
- All API responses from synthetic data include `"source": "SYNTHETIC"` marker
