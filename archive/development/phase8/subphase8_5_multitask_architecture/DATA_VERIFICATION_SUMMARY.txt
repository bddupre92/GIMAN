MISSING LABEL HANDLING STRATEGY
  - Problem: Not all patients have all 4 labels
    * Progression/Conversion: 127 patients
    * SAA/Diagnostic: 608 observations (different cohort)
  - Solution: Masked loss computation
    * Only compute loss for tasks where labels are available
    * Use label_mask per task in PyG Data objects
    * Loss: L_total = sum(w_i * L_i) for i where mask_i == True
