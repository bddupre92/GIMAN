\begin{abstract}
We present an artifact-backed internal validation update for FUZZY GIMAN, a neuro-fuzzy graph framework for Parkinson's prognosis. This manuscript reports reproducible results under a locked patient-level split contract (\texttt{PATNO,time,event,saa\_label}), with explicit calibration analysis, explainability outputs, preprocessing transparency, and digital twin sensitivity diagnostics. Internal cycle gates pass for proxy-dependency checks, imbalance handling, calibration improvement, sensitivity boundedness, and metric-contract separation. External validation remains required before clinical deployment claims.
\end{abstract}

\begin{IEEEkeywords}
Parkinson's disease, neuro-fuzzy models, graph neural networks, explainable AI, digital twin, clinical AI validation
\end{IEEEkeywords}

\section{Introduction}
Parkinson's disease progression modeling requires methods that can represent heterogeneity, uncertainty, and longitudinal dynamics. FUZZY GIMAN combines graph-based population reasoning with differentiable fuzzy logic to improve interpretability and robustness while maintaining predictive utility. In this update, we report only artifact-backed metrics and figures generated from the current canonical pipeline.

\section{Methods}
\subsection{Data Contract and Evaluation Protocol}
All evaluations use the locked contract:
\begin{itemize}
\item Patient key: \texttt{PATNO}
\item Survival keys: \texttt{time}, \texttt{event}
\item Classification key: \texttt{saa\_label}
\item Patient-disjoint split with deterministic split hash
\end{itemize}

\subsection{Validation Stack}
The internal validation stack includes:
\begin{itemize}
\item Baseline benchmarking (logistic regression, random forest, SVM-RBF)
\item FUZZY GIMAN discrimination and calibration
\item Permutation-based feature importance
\item Digital twin counterfactual sensitivity scans (moderate and stress settings)
\item Multimodal readiness and preprocessing transparency audits
\item Clinical hardening gate review cycles (C1--C6)
\end{itemize}

\section{Results}
\subsection{Discrimination and Calibration}
On the canonical internal split, FUZZY GIMAN shows AUC 0.590 and PR-AUC 0.285 for the current audited checkpoint. Raw probabilities are overconfident, but post-hoc calibration materially improves reliability (ECE and Brier). Baselines and confidence intervals are summarized in Table~\ref{tab:internal_metrics}.

\section{Discussion}
This audit confirms that FUZZY GIMAN currently satisfies internal reproducibility and governance requirements, with robust explainability and digital twin sensitivity diagnostics. However, external validation evidence is still insufficient for clinical deployment claims. The model should therefore be framed as \emph{internally validated and clinically promising}, not clinically deployed.

\section{Limitations and Next Steps}
\begin{itemize}
\item External cohort validation remains mandatory.
\item Transportability, subgroup robustness, and longitudinal drift performance need formal reporting.
\item Real-time digital twin updates require operationalized ingestion and versioned refresh orchestration.
\end{itemize}

\section{Conclusion}
FUZZY GIMAN demonstrates a reproducible, explainable internal framework for Parkinson's prognosis and digital twin development. The current pipeline is publication-ready for internal-evidence reporting and dissertation progression, with external validation as the primary remaining gate for clinical-grade claims.
